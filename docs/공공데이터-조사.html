조사 노트 · 2026-08-18

공공데이터에 단차 정보가 있을까?

보행 약자용 노면 파손·단차 서비스를 만들기 전에, 이미 공공데이터에 같은 정보가 존재하는지 확인했다. 조사 범위: 공공데이터포털(data.go.kr), 서울 열린데이터광장, 인천데이터포털, AI Hub, 국토교통부·행정안전부·보건복지부 개방 데이터.

핵심 결론

"보도 위 어느 좌표에 몇 cm 단차가 있다" 수준의 데이터는 전국 어디에도 개방되어 있지 않다.

  • 존재하는 공공데이터는 전부 간접 데이터다 — 건물 단위 "단차 유무", 위치 없는 집계 통계, 배경 지도용 보행 네트워크.
  • 이 공백은 프로젝트의 약점이 아니라 존재 이유다. 우리 서비스가 만드는 데이터가 곧 공공데이터의 빈칸을 채우는 시민 생성 데이터다.
  • 공공데이터의 올바른 역할은 대시보드의 배경 레이어(도보 네트워크, 경사도, 횡단보도, 편의시설 위치)와 문제 규모의 정량화(실태조사 통계)다.

1. 계층별 존재 여부

계층존재 여부실제 데이터
보도 좌표 단위 단차·파손 없음 — 이 프로젝트가 만들 데이터
건물·POI 단위 "단차 유무" 부분 장애인 편의시설 설치현황(주출입구 단차 제거 여부), 제주 무장애여행정보
보행 네트워크 링크·노드 부분 인천 이동약자 보행자 네트워크(현재 내려감), 서울 도보 네트워크, 서울 경사도
집계 통계 (위치 없음) 있음 교통약자 이동편의 실태조사 — 기준적합률 등
노면 파손 신고 간접 안전신문고 민원 (위치별 원시데이터 개방 제한적)
AI 학습용 이미지 있음 AI Hub 인도보행 영상 — 보도 파손·점자블록 파손 라벨 포함

2. 데이터별 상세

2.1 건물·POI 단위 — "단차 유무"만, 좌표 아님

  • 보건복지부_장애인 편의시설 설치현황 — 건물 주출입구 접근로·단차 제거 여부 등을 시설(건물) 단위로 제공. 보도 위 위치가 아니라 건물 단위 속성이다.
  • 전국장애인편의시설표준데이터 — 시설명·주소·보유 편의시설 목록.
  • 제주 무장애여행정보 (제주특별자치도, CSV/JSON/XML) — 관광지별 단차 여부. 공공데이터포털에서 "단차"로 검색되는 42건의 대부분이 이 시리즈다. 즉 "단차" 검색 결과조차 보도 데이터가 아니라 관광지 접근성 안내다.

2.2 보행 네트워크 — 배경 지도로는 유용, 단차 높이는 없음

  • 인천광역시 이동약자 보행자 네트워크 (주요단지·보호구역·건물 등 분할, SHP) — 2021년 공공데이터 기업매칭 지원사업으로 구축된 이동약자용 정밀 길안내 네트워크. 학교 소재지(인천)와 일치하는 가장 유망한 데이터였으나, 2026-08 현재 data.go.kr 페이지가 404로 내려간 상태. 인천데이터포털 또는 인천시 스마트도시담당관 문의로 확보 가능 여부 확인 필요 (→ 미해결 질문).
  • 서울시 자치구별 도보 네트워크 공간정보 (공공데이터포털 파일) — 보행자도로 노드·링크. 육교·계단·횡단보도·지하철 출입구 등 유형 코드는 있으나 단차 높이·노면 상태 속성은 없음.
  • 서울시 경사도 — 경사도는 별도 데이터로 존재. 단, 경사(기울기)와 단차(수직 턱)는 다른 개념이다.
  • 전국횡단보도표준데이터, 전국보행자우선도로표준데이터 — 배경 레이어용.

2.3 집계 통계 — 문제 규모는 알 수 있으나 "어디"는 모름

교통약자 이동편의 실태조사 (국토교통부·한국교통안전공단, 홀수 해 특별·광역시 / 짝수 해 도 지역) — 보도 등 이동편의시설의 기준적합률을 조사. 2024년 조사 기준 교통약자는 1,613만 명(총인구의 31.5%), 도 지역 이동편의시설 적합률 79.3%. "몇 %가 부적합한지"는 알 수 있으나 "어느 보도의 어느 지점인지"는 알 수 없다 — 발표에서 문제 규모를 정량화하는 근거로 사용.

2.4 노면 파손 신고 — 채널은 있으나 데이터 개방은 제한적

안전신문고 — 포트홀·도로 파손을 시민이 신고하는 채널. 신고 위치별 원시 데이터는 개방되지 않으며, 국민권익위원회의 포트홀 민원 분석 보고서 같은 집계 분석만 존재. 또한 신고 대상이 주로 차도 포트홀이고, 보도 단차는 신고 체계상 별도 항목이 아니다.

2.5 AI 학습용 — 이미지 기반, IMU 방식과 보완 관계

  • AI Hub 인도보행 영상 — 보도 표면 20종(재질·파손 상태 포함) 세그멘테이션 + 장애물 29종 바운딩박스. 보도블록 파손·점자블록 파손 판별을 목표로 구축. 위치 데이터가 아니라 학습용 이미지이므로 지도를 만들 수는 없지만, (선택 기능) 사진 인증·검증 모델의 학습 데이터로 활용 가능.
  • 고해상도 도로노면 이미지 데이터 — 차도 중심이라 우선순위 낮음.

3. 프로젝트에의 함의 — 공백이 곧 차별점

  1. 문제 정의의 데이터 근거: "기존 지도에 단차 정보가 없다"는 주장을 넘어, "공공데이터 전체를 조사해도 단차 위치 데이터가 없다"고 말할 수 있다. 검색 근거: data.go.kr "단차" 검색 42건 전수 확인 결과 보도 데이터 0건.
  2. 문제 규모의 정량화: 실태조사 통계(교통약자 1,613만 명, 31.5%)로 대상의 크기를 제시.
  3. 서비스 포지셔닝: 우리 데이터 = 공공데이터의 공백을 채우는 시민 생성(crowdsourced) 데이터. 인천시가 2021년에 이동약자 네트워크를 구축하고도 유지하지 못한 것(404) 자체가 "센서 기반 자동 수집"의 필요성을 보여준다 — 사람이 조사해 만든 데이터는 갱신이 멈추면 죽는다.
  4. 공공데이터의 역할: 대시보드의 배경 레이어. 서울·인천 도보 네트워크 위에 우리가 측정한 단차·파손 포인트를 얹는 구조가 자연스럽다.

4. 발표 FAQ 활용 (워크시트 1의 FAQ 재료)

이런 정보는 공공데이터에 이미 있지 않나요?

저희도 그렇게 생각해서 먼저 조사했습니다. 공공데이터포털에서 "단차"로 검색되는 42건은 전부 관광지·건물 단위 안내이고, 보도 위 좌표 단위의 단차·파손 데이터는 없습니다. 국가 실태조사도 "전국 보도의 몇 %가 기준 부적합"이라는 통계만 있을 뿐 "어디가" 위험한지는 알려주지 않습니다. 저희 서비스는 바로 그 빈칸 — 위치 데이터를 센서로 자동 수집해 채웁니다.

인천시가 2021년에 비슷한 데이터를 만들지 않았나요?

맞습니다. 이동약자 보행자 네트워크가 구축됐지만 현재 공공데이터포털에서 내려간 상태입니다. 사람이 직접 조사하는 방식은 비용 때문에 갱신이 멈추기 쉽습니다. 저희는 시민이 걷기만 해도 데이터가 갱신되는 구조라 이 문제를 피할 수 있습니다.

미해결 질문 (다음 단계)

  1. 인천 이동약자 네트워크 SHP 확보: 인천데이터포털 검색 또는 인천시 스마트도시담당관 문의로 원본 확보 가능한지 확인. 확보되면 속성에 단차·경사 필드가 실제로 있는지 검증 → 대시보드 배경 레이어 또는 비교 기준(ground truth)으로 활용.
  2. 서울 도보 네트워크 실제 컬럼 확인: 파일을 내려받아 링크 속성에 활용 가능한 필드(계단 유형 등)가 무엇인지 확인.
  3. 안전신문고 인천 지역 민원 통계: 지자체 정보공개청구로 동 단위 포트홀·보도 민원 건수를 받으면 "수요 히트맵"의 보조 근거가 될 수 있는지.
